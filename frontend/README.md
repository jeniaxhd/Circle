# Circle — локальный интерфейс для тестирования

Без React, сборки и сторонних библиотек. Требуется Node.js 20+.

## Запуск

В одном терминале запусти backend обычным способом:

```powershell
cd C:\Users\jekax\Documents\Circle\backend
npm run start:dev
```

PostgreSQL должен быть запущен (из корня проекта: docker compose up -d).

Во втором терминале:

```powershell
cd C:\Users\jekax\Documents\Circle\frontend
npm start
```

Открой http://127.0.0.1:5173. Устанавливать зависимости frontend не нужно.

## Как пользоваться

1. Войди или зарегистрируй пользователя.
2. Создай круг либо вставь приглашение и нажми «Вступить в круг».
3. Выбери круг, раздел и действие. Адрес, HTTP-метод и авторизация подставляются автоматически.
4. Для чтения, изменения и удаления выбери запись из списка.
5. В разделе комментариев сначала выбери пост.
6. Через «Войти ещё одним» добавь второго пользователя. Аккаунты можно переключать для проверки прав.
7. HTTP-статусы и JSON-ответы видны под формой. Нажми запрос в журнале, чтобы посмотреть его ответ.
8. Для нестандартных проверок есть свёрнутая форма произвольного запроса.

Кнопки позволяют проверять ошибки доступа. Окончательные разрешения проверяет backend.
Токены сохраняются только в sessionStorage текущей вкладки. Пароли не сохраняются.
Токены скрыты в журнале. «Выйти» забывает выбранный аккаунт.

Новую ссылку приглашения можно скопировать после создания. Список не восстанавливает токены.
Открытие ссылки не добавляет пользователя в круг: нужно войти и нажать «Вступить в круг».

Сервер слушает только 127.0.0.1. /api проксируется на backend; менять CORS не требуется.
Это локальный инструмент разработки.

## Другие порты

```powershell
$env:PORT = '5174'
$env:API_TARGET = 'http://127.0.0.1:3001'
npm start
```

Для автоматического перезапуска после изменений: npm run dev.
